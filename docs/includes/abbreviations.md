*[AR]: Absorption ratio — fraction of cross-asset variance explained by the top principal components (Kritzman et al. 2011). See Foundations.
*[AUC]: Area under the ROC curve — probability a random positive scores above a random negative; 0.5 is no skill. See Foundations › Scoring rules.
*[BSS]: Brier skill score — 1 − Brier / Brier of the constant base-rate forecast; 0 is "no better than the base rate". See Foundations › Scoring rules.
*[ECE]: Expected calibration error — size-weighted mean |hit-rate − stated confidence| across reliability bins. See Foundations › Scoring rules.
*[GBM]: Gradient-boosted machine — an ensemble of shallow decision trees; the non-linear baseline. See Foundations › Models.
*[HAR-RV]: Heterogeneous autoregressive realized variance (Corsi 2009) — tomorrow's variance on daily/weekly/monthly past variance. See Foundations › Models.
*[HMM]: Hidden Markov model — an unobserved regime that switches with fixed probabilities; retired from the note (ADR-0004). See Foundations › Models.
*[LOCO]: Leave-one-crisis-out cross-validation — the drawdown episodes are the folds. See Foundations › Inference.
*[NFCI]: Chicago Fed National Financial Conditions Index, weekly; positive = tighter than average. One of the three bucket dimensions. See Foundations.
*[OAS]: Option-adjusted spread — a bond's yield over Treasuries after removing the value of embedded options. See Foundations › Spread.
*[PIT]: Point-in-time (data as knowable on the date) — or, in score_distributions, the probability integral transform. See Foundations › PIT (two meanings).
*[SEP]: Summary of Economic Projections — the FOMC's quarterly "dots"; FRED serves only the current vintage. See Foundations.
*[SPF]: Survey of Professional Forecasters — the Philadelphia Fed's quarterly consensus of private economists. See Foundations.
*[VRP]: Variance risk premium — implied minus expected realized variance (VIX² − HAR-RV forecast). See Foundations.
*[WP]: Work package — a unit of a roadmap phase.
*[ADR]: Architecture decision record — one page per load-bearing choice, under Decisions.
*[KB]: Knowledge Base — the numbered record of measured results, negatives included.
*[IMP]: Improvement-track experiment on a component that already exists.
*[GFC]: The 2008 global financial crisis — the composite's warm-up year.
*[OLS]: Ordinary least squares.
*[PCA]: Principal component analysis — the eigen-decomposition behind the absorption ratio.
*[CI]: Confidence interval — or, in operations context, continuous integration (the GitHub Actions runs).
